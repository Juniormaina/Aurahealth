# Coach Aura 3D model

`coach_aura.glb` is the Mixamo **Xbot** character bundled with the [three.js examples](https://github.com/mrdoob/three.js) (`examples/models/gltf/Xbot.glb`).

Used under the three.js examples distribution for Aura Health’s training viewport: skinned athletic humanoid with idle / locomotion clips, driven procedurally for calisthenics and yoga poses.
