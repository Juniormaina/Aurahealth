# Coach Aura trainer models

| File | Role |
|------|------|
| `male_trainer.glb` | Athletic male trainer (gym vest / shorts styling at runtime) |
| `female_trainer.glb` | Athletic female trainer (yoga outfit styling at runtime) |
| `coach_aura.glb` | Legacy alias of the Mixamo Xbot base mesh |

Base mesh: Mixamo **Xbot** from the [three.js examples](https://github.com/mrdoob/three.js) (`examples/models/gltf/Xbot.glb`), Mixamo humanoid rig (`mixamorig*`) with idle / locomotion clips. Outfit and proportion differences are applied in `CoachCharacter` when the user toggles Male / Female.
