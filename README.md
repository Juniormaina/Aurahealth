# AuraHealth

AuraHealth is a gamified wellness and adherence platform built on **Avalanche**.  
It helps users stay consistent with daily health routines (hydration, medication, sleep, activity) by turning them into engaging challenges with evolving digital companions, streaks, and sponsor‑backed rewards.

---

## 🚀 Features
- **Daily Check‑Ins**: Track hydration, medication, sleep, and activity.
- **Gamified Companion**: Evolve your digital health pet as you maintain streaks.
- **Rewards System**: Earn Cowries, XP, and vouchers funded by sponsors (clinics, NGOs).
- **AI Health Coach**: Personalized feedback and habit suggestions.
- **Secure & Scalable**: Smart contracts deployed on Avalanche C‑Chain for fast, low‑cost transactions.

---

## 🛠️ Tech Stack
- **Frontend**: Next.js + React
- **Backend**: Firebase (authentication, data storage)
- **Blockchain**: Avalanche C‑Chain (smart contracts via Hardhat)
- **Integration**: Web3 libraries for contract interaction
